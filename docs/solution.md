# Proposed Solution – NexGlove

## NexGlove

NexGlove is an AI-based wearable, detachable, universal controller interface that enables seamless cross-device interaction through customizable buttons, gestures and software-defined (Web/App) actions.

## Key Features

- AI Gesture Recognition
- Intelligent Motion Processing
- Programmable Bluetooth HID
- Customizable User Interface
- Wireless & Low-Latency Operation
- Gesture-Based Scrolling
- Multi-Mode Operation
- Personalized Control Mapping
- Portable & Wearable Design
- Universal Control
- Custom Profiles
- Modular Design
- Economically Feasible
- Natural Hand-Controlled Cursor

## Core Interaction

NexGlove captures hand movement, orientation and button inputs using the MPU6050, INMP441 and four physical buttons. The system processes sensor inputs and uses AI-based gesture recognition to interpret hand movements and trigger intelligent commands.

It enables wireless cursor control, clicking, scrolling, media controls and keyboard functions through Bluetooth HID.
