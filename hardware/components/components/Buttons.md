# Buttons

## Role in NexGlove

Physical buttons provide direct user input for controlling computer actions.

## Main Functions

- Detect button presses.
- Trigger assigned commands.
- Support customizable control mapping.

## NexGlove Button Setup

NexGlove uses four physical buttons:

- B1
- B2
- B3
- B4

These buttons can be assigned to different actions through the software interface.
