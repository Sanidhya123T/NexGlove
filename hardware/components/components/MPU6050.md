# MPU6050

## Role in NexGlove

The MPU6050 is used to detect hand movement and orientation.

## Main Functions

- Measures motion and orientation-related data.
- Captures changes caused by hand movement.
- Provides motion data to the ESP32 for processing.

## Use in NexGlove

The MPU6050 provides the motion input required for cursor control and gesture-based interaction.
