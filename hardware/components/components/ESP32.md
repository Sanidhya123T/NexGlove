# ESP32

## Role in NexGlove

The ESP32 acts as the main microcontroller of the NexGlove hardware system.

## Main Functions

- Reads input from the connected sensors and buttons.
- Processes the received input data.
- Handles wireless communication.
- Supports Bluetooth-based interaction with the computer.

## Use in NexGlove

The ESP32 forms the core control unit of the glove and connects the hardware input layer with the computer interaction layer.
